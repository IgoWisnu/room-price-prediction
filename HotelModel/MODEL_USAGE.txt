OVERVIEW
--------
  This model predicts the nightly room price (IDR) for hotels, villas and
  resorts in Bali, Indonesia.  It was trained on data scraped from tiket.com
  using an XGBoost regressor with Optuna hyperparameter tuning.

  Target variable : log_price  (log1p of price in IDR)
  Output          : Call numpy.expm1(log_price) to recover IDR value.
  Test MAPE       : ~36.5%  |  R² : 0.756  |  RMSE_log : 0.438


FILES NEEDED
------------
  bali_price_model.json    — XGBoost model weights  (load with xgb.Booster)
  bali_preprocessor.pkl    — Contains:
                               - target_encoder       : fitted TargetEncoder for kecamatan
                               - feature_cols         : ordered list of 32 feature names
                               - room_size_m2_median  : 34.0  (imputation fallback)

QUICK START — SINGLE PREDICTION
---------------------------------

  import numpy as np
  import pandas as pd
  import pickle
  import xgboost as xgb

  # 1. Load model and preprocessor
  model = xgb.Booster()
  model.load_model("bali_price_model.json")

  with open("bali_preprocessor.pkl", "rb") as f:
      preproc = pickle.load(f)

  # 2. Build a single-room input dict
  room = {
      # --- Numeric ---
      "log_review"        : np.log1p(350),   # log1p of number of reviews
      "star_rating"       : 4,               # 1–5 stars
      "rating"            : 8.5,             # guest score (0.0 = no reviews)
      "no_review"         : 0,               # 1 if rating == 0.0, else 0
      "room_size_m2"      : 35.0,            # set to None if unknown
      # --- GPS ---
      "latitude"          : -8.6905,         # from scraper / Google Maps
      "longitude"         : 115.1673,
      # --- Brand ---
      "is_luxury_brand"   : 0,               # 1 if hotel is a luxury chain
      # --- Hotel facilities (from hotel_facilities text) ---
      "has_pool"          : 1,
      "has_wifi"          : 1,
      "has_ac"            : 0,
      "has_gym"           : 0,
      "has_spa"           : 1,
      "has_restaurant"    : 1,
      "has_parking"       : 1,
      # --- Room / package flags ---
      "has_breakfast"     : 1,
      "has_kitchen"       : 0,
      "has_bathtub"       : 1,
      "has_balcony"       : 0,
      "has_ocean_view"    : 0,               # from room_facilities column
      "is_free_cancellation": 0,
      "room_tier"         : 2,               # 1=standard,2=superior/deluxe,3=premier,
                                             # 4=suite,5=villa/penthouse
      "value_added_count" : 1,               # count of extras in package_value_added
      # --- Room view / pool flags (from room_name) ---
      "has_pool_view"     : 1,
      "has_garden_view"   : 0,
      "has_ocean_view2"   : 0,               # ocean/sea/beach view in room name
      "has_private_pool"  : 0,
      "has_pool_access"   : 0,
      "has_nature_view"   : 0,               # jungle/valley/mountain view
      "has_city_view"     : 0,
      # --- Kecamatan (provide the raw text — encoder handles it) ---
      "kecamatan_cleaned" : "Seminyak",
  }

  # 3. Build DataFrame and encode kecamatan
  X = pd.DataFrame([room])
  X["room_size_m2"] = X["room_size_m2"].fillna(preproc["room_size_m2_median"])
  X["kecamatan_te"] = preproc["target_encoder"].transform(
      X[["kecamatan_cleaned"]]
  )["kecamatan_cleaned"]

  # 4. Select features in the correct order and predict
  dmat   = xgb.DMatrix(X[preproc["feature_cols"]])
  log_p  = model.predict(dmat)[0]
  price_idr = int(np.expm1(log_p))

  print(f"Predicted price : IDR {price_idr:,}")

MODEL ACCURACY NOTES
--------------------

  - Average error is ~36% MAPE across the full test set.
  - Error distribution on the 466-row test set:
      < 10% error  : 17.0%  of rooms  (near-perfect)
      10–25% error : 22.1%  of rooms  (good)
      25–50% error : 36.7%  of rooms  (acceptable)
      > 50% error  : 24.2%  of rooms  (high error)

  - The model tends to OVER-predict (284 vs 182 under-predictions).
    Reason: most over-predictions are for small budget guesthouses or
    homestays where the price is lower than what their facilities suggest.

  - Worst predictions occur for:
      a) Ultra-luxury suites (>5M IDR) — brand prestige not fully captured
      b) Rooms with unusual pricing not correlated with listed facilities
      c) Properties in sparse kecamatan (e.g. Nusa Penida, Lovina) where
         training data is limited

  - Best predictions occur for mid-range properties (500k–2M IDR) in
    Seminyak, Kuta, Legian, and Ubud.
